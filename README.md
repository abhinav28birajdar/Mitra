# Mitra AI - Career & Learning App (UI/UX Case Study)

Mitra AI is a high-end, AI-powered career learning platform designed for modern professionals. This project is a **frontend-only** implementation focused on premium UI design, glassmorphic aesthetics, and seamless user experiences using React Native and Expo.

## ✨ Project Highlights
- **Premium UI/UX**: Crafted with a "Glassmorphism" aesthetic, vibrant gradients (HSL tailored), and smooth micro-animations.
- **AI-Driven Experience**: Interactive AI Coach chat interface, personalized learning paths, and intelligent recommendations.
- **Full Navigation Flow**: Comprehensive navigation system using React Navigation, including deeply nested stacks, custom tab bars, and translucent modals.
- **Modern Tech Stack**: Built with TypeScript, Expo, NativeWind (Tailwind), and Lucide-inspired iconography.

## 📱 Features & Screens

### 🔐 Authentication & Onboarding
- **Interactive Splash & Onboarding**: Animated branding and feature highlights.
- **Complete Auth Flow**: Sign In, Sign Up, Forgot Password, and **Visual OTP UI**.
- **AI Personalization Setup**: Multi-step setup flow including goal selection, skill assessment, and interest mapping.
- **AI Loading Screen**: Stunning animation while the AI "generates" your personalized experience.

### 🏠 Main Application
- **Dynamic Dashboard**: Personalized greeting, AI recommendation cards, daily streaks, and learning progress summary.
- **Explore & Search**: Semantic search for careers and courses with category filters.
- **AI Chat Coach**: A sophisticated chat interface for interaction with "Mitra," the AI career companion.
- **Progress Tracking**: Detailed analytics, weekly activity charts (ChartKit), and skill proficiency levels.

### 🎓 Learning & Career
- **Learning Path Detail**: Syllabus breakdown with locked/unlocked modules and progress tracking.
- **Module Lesson**: Video player UI, lesson summary, and key takeaways.
- **Quiz & Assessment**: Interactive quizzes with instant feedback, correct/incorrect states, and explanations.
- **Certificates**: Verifiable badge UI with preview and share capabilities.

### ⚙️ Settings & Social
- **Comprehensive Settings**: Privacy, Security (with security scoring), Theme (Light/Dark toggles), and Help & Support.
- **Social Features**: Notification center, Chat list, User profile viewing, and Profile editing.
- **Special Modals**: Translucent "User Actions" sheet and high-res "Image Preview."

## 🛠️ Tech Stack
- **Framework**: [React Native (Expo)](https://expo.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Navigation**: [React Navigation v6](https://reactnavigation.org/)
- **Styling**: [NativeWind (Tailwind CSS)](https://www.nativewind.dev/)
- **Icons**: [Expo Vector Icons (Ionicons)](https://docs.expo.dev/guides/icons/)
- **Charts**: [React Native Chart Kit](https://github.com/indie-it/react-native-chart-kit)
- **Animations**: [Animated API](https://reactnative.dev/docs/animated) & [Expo Linear Gradient](https://docs.expo.dev/versions/latest/sdk/linear-gradient/)

## ⚠️ Important Note
This is a **Frontend-only** implementation. There is no actual backend, database, or API integration. All data is managed via local mock constants to demonstrate the UI and UX flows.
